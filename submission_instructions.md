# Submission Instructions

Submit a zip or GitHub repository containing:

1. Source code for backend and frontend.
2. Dataset used and any preprocessing scripts.
3. README with setup and run commands.
4. Screenshots or short demo notes.
5. Evaluation results and limitations.
6. Railway deployment link or deployment evidence:
   - **Production URL:** https://web-production-18808.up.railway.app
   - **Health Check:** https://web-production-18808.up.railway.app/api/health
   - **Interactive API Docs:** https://web-production-18808.up.railway.app/docs

Do not hard-code secrets or API keys. Use environment variables for any external LLM or embedding API.
